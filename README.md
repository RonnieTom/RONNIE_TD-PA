## 配置

`config.lua`：

```lua
Config.Vehicles = {
    ['police'] = {
        offset = vector3(-0.02, 0.66, 0.24), -- 车体本地：缆线/喇叭
        range = 130.0,                       -- 最远听见距离（米）
    },
}
```

按键默认 `RMENU`（右 Alt），可在 FiveM 键位设置里改「车载 PA 扩音器（按住）」。无 HUD / 时长上限，松手即停。

## 用法

1. 坐到配置座位（默认驾驶/副驾）→ **按住** 键喊话  
2. 车外打开对应车门 →「拿取扩音器」→ 按住键喊话 →「归还扩音器」  
3. 一辆车同时只能一人拿取/喊话  
4. 与车台手咪车外拿取互斥  

## 启动

`server.cfg`：

```
ensure RONNIE_TD_PA
```
